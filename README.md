## Selected projects

### Infomed — AI-assisted symptom pre-triage prototype

A web prototype that organizes reported symptoms and returns a structured urgency assessment, warning signs and suggested next steps.

- **Problem explored:** helping organize information at the first point of contact in a hospital journey.
- **Evidence in the repository:** a typed, schema-constrained response with five urgency levels; separate React interface, AI service and TypeScript types.
- **Built with:** TypeScript, React, Vite, Tailwind CSS and Google Gemini via `@google/genai`.
- **Status:** prototype only—not clinically validated and not a diagnosis. No clinical outcomes or real-world impact have been verified.
- **Repository:** [MiguelBessornia/infomed](https://github.com/MiguelBessornia/infomed)

### RedeVita — healthcare operations prototypes

Academic web applications for organizing medicine inventory and related workflows such as donations, patients, doctors and pharmacies.

- **Problem explored:** making healthcare and pharmacy operations easier to organize through a web application.
- **Evidence in the repositories:** Flask routes and modules for inventory and related workflows, documented local setup, and database options in project configuration.
- **Technologies observed:** Python, Flask, SQLAlchemy, HTML, CSS and JavaScript; SQLite, MySQL and PostgreSQL are documented/configured options.
- **Status:** academic prototypes; production readiness has not been established. Security hardening and automated tests are important next steps.
- **Repositories:** [trabalho-marcos-pratica2](https://github.com/MiguelBessornia/trabalho-marcos-pratica2) · [projeto-roxo](https://github.com/MiguelBessornia/projeto-roxo)

The two RedeVita repositories have overlapping scope; I have not presented them as separate products or assumed their relationship.
